\begin{abstract}	
Il progetto di tesi ha come obbiettivo la progettazione di un software full-stack di supporto
alle vendite del reparto commerciale dell'azienda Cepi S.p.a.\cite{Cepi}
 azienda metalmeccanica forlivese.
 %Perchè proprio la cepi?
L'azienda è specializzata nella produzione di impianti di stoccaggio.
Il progetto di tesi racchiude in sé tutte le fasi di sviluppo partendo dall'analisi 
dell' As-Is, procedendo con la raccolta dei requisiti, fino alla progettazione 
del database e alla realizzazione del software.
IL database è stato progettato e costruito su motore Microsoft SQL Server,
 mentre il software è stato realizzato in linguaggio \csharp{} 
 con l'utilizzo del framework \dotnet{}.
\dotnet{} è stato utilizzato con l'intento del cross-platform,
si è quindi, oltre alla progettazione del software, progettato anche le interfacce grafiche
per le piattaforme desktop e mobile.
\end{abstract}
